# Using StorySketch

1. **Pick a page** (top), add characters and props from the left panel. **New** offers one blank page or a sample project to explore.
2. **Pose**: drag the dots on a selected character. Orange = hands, feet, paws, tail tip. Blue = elbows, knees, tail joint. Green = lean, head, neck.
   - Shift-drag a hand/foot turns just the forearm/shin. Double-press an elbow/knee to bend it the other way.
   - Animals have their own preset poses (Stand, Walk, Run, Sit, Lie down, Beg, Bark, Sniff, Happy).
3. **Layering**: `[` / `]` (Shift = to back/front) or the Layers list. For hands on top of a drum: select the figure, tick the limb under *Layering*, move the "front limbs" layer above the drum.
4. **Select several** with Ctrl/Shift-click or by dragging a box; the purple handles resize/rotate the group.
   - **Group** Ctrl+G (Ctrl+Shift+G ungroups). **Lock** Ctrl+Shift+L. **Zoom** Ctrl + wheel or the − / + buttons; Space-drag to pan; Ctrl+0 fits the page.
   - **Alt+click** steps through everything stacked under the pointer.
5. **Style**: *Page* tab → *Drawing style*. `P` toggles the styled preview (editing is always clean and fast). Chalk offers a blackboard page colour.
6. **Export** → Selection or Page → PNG/SVG. For AI image tools pick *Clean lines*, the paper colour as background, 1×.
7. **Characters**: the *Character designer* edits looks and changes the skeleton (Person ↔ four-legged animal); *New character from template…* includes Dog, Cat, Dinosaur.

Project files: **Save as…** once, then **Save** / Ctrl+S. Older files made with the tool's former name (Crayon Poser) open normally.
